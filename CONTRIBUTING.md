# Contributing Guidelines

## File Header Documentation
As per corporate policy, every new file created in this repository MUST contain a standardized header. Every time you modify a file, you MUST append a line to the `Changes` section.

### Template:
```python
# ==========================================
# File: [filename]
# Description: [Brief description of what this file does]
# Author: [Your Name / AI Agent]
# Created: YYYY-MM-DD
# Changes:
#   - YYYY-MM-DD ([Author]): [What was changed/added/removed]
# ==========================================
```

*For languages like TypeScript/JavaScript, use `//` or `/* */` instead of `#`.*

## General Rules
1. **No direct commits to `main`**: Always use feature branches and PRs.
2. **Commit Messages**: Follow standard conventional commits (`feat:`, `fix:`, `docs:`, `refactor:`).
3. **Documentation**: Keep `CHANGELOG.md` updated with major additions.

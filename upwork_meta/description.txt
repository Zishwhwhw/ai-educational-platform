Built a comprehensive online learning platform for programming with AI-powered course generation using Google Gemini API, integrated Monaco Code Editor for in-browser coding, real-time collaboration features, Docker-based infrastructure, and a gamified reward system. The platform includes a FastAPI backend with SQLAlchemy ORM, Alembic migrations, JWT authentication, and a Next.js 14 frontend with React 19 and TypeScript.
